# Rookie Quest Slicer v0.2

Mobile-first slicing UI for the Elegoo Neptune 3 Pro.

Current test scope: STL/3MF, 0.4 mm nozzle, PLA+, five simple profiles, optional supports, access PIN and downloadable G-code.

The server runs PrusaSlicer CLI in a Docker container. Generated G-code remains TEST PROFILE output until we validate it with a supervised printer test.
