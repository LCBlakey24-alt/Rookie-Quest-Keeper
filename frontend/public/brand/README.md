# Rookie Quest Keeper brand assets

Canonical direction: **Guild Ledger**.

Keeper has its own product identity inside the Rookie Quest family. The current owner-supplied logo (2 November 2026) is a white vector wordmark with an orange-to-red underline against the ink-navy site.

## Current canonical assets

- `rookie-quest-keeper-main-logo.svg` — **canonical main and compact wordmark**, supplied by the product owner and converted to font-independent vector paths. Cropped viewBox removes export padding, not artwork.
- `keeper-primary-logo.png` — legacy raster fallback for existing social preview metadata; **not** the visible site wordmark.
- `keeper-compact-wordmark.png` — legacy raster file; not used by the shared logo component
- `keeper-symbol.png` — wax-seal + quill product mark
- `keeper-favicon.png` — simplified small-size mark
- `keeper-app-icon.png` — square installed-app/PWA icon

The matching browser files are `/favicon.png` and `/apple-touch-icon.png`.

Older `rqk-logo-*`, rook/book/shield and generic Rookie Quest logo files are legacy compatibility assets only and must not be used for new Keeper UI.

Canonical palette:
- Ink Navy `#0B1B2B`
- Slate `#0B1B2B`
- Ledger Grey `#0B1B2B`
- Parchment `#EADFC8`
- Brass `#C9A96B`
- Wine Seal `#7F2D2D`

## Current deployment scope

The new owner-supplied SVG is used for main website branding, compact wordmark and sign-in wordmark. Keep the existing square `keeper-symbol.png`, app icon, favicon and Apple touch icon until the owner approves a new *square* symbol. Do not stretch the horizontal wordmark into a square icon. The original SVG remains in OneDrive under Rookie Quest / 00 - Brand & Visual Identity / 01 - Logos / Keeper.
