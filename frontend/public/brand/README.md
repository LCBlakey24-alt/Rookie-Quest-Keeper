# Rookie Quest Keeper brand assets

Canonical direction: **Guild Ledger**.

Keeper has its own product identity inside the Rookie Quest family. The current owner-supplied logo (2 November 2026) is a white vector wordmark with an orange-to-red underline against the ink-navy site.

## Current canonical assets

- `rookie-quest-keeper-main-logo.svg` — **canonical main and compact wordmark**, supplied by the product owner and converted to font-independent vector paths. Cropped viewBox removes export padding, not artwork.
- `keeper-primary-logo.png` — legacy raster fallback for existing social preview metadata; **not** the visible site wordmark.
- `keeper-compact-wordmark.png` — legacy raster file; not used by the shared logo component
- `rookie-quest-keeper-app-icon.svg` — **canonical square icon** (owner-supplied artwork, true vector paths, transparent rounded corners, navy and citrus gradient).
- `/favicon.png` (64px) — PNG fallback for browsers without SVG favicon support.
- `/apple-touch-icon.png` (180px) — Apple touch icon with solid navy padding.
- `/icons/keeper-192.png` and `/icons/keeper-512.png` — PWA icon PNG fallbacks.
- `/icons/keeper-maskable-512.png` — separate safe-area padded PWA maskable icon.
- `keeper-symbol.png`, `keeper-favicon.png` and `keeper-app-icon.png` — historical/compatibility artwork; do not reference in new product UI.

The matching browser files are `/favicon.png` and `/apple-touch-icon.png`.

Older `rqk-logo-*`, rook/book/shield and generic Rookie Quest logo files are legacy compatibility assets only and must not be used for new Keeper UI.

Canonical palette:
- Ink Navy `#0B1B2B`
- Slate `#0B1B2B`
- Ledger Grey `#0B1B2B`
- Parchment `#EADFC8`
- Brass `#C9A96B`
- Wine Seal `#7F2D2D`

## Current deployment scope

The owner supplied a separate approved square `RQ/K` icon in November 2026. Use it as the website mini mark and browser favicon, and the matching exported PNGs for iOS and PWA installation. The horizontal Keeper wordmark remains unchanged. The source SVG and original PNG are retained in OneDrive under Rookie Quest / 00 - Brand & Visual Identity / 01 - Logos / Keeper.
